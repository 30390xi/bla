# bla-agents 1.5.2 — Android DEX external-invoke counter (REA #8154)

**Date:** 2026-10-31 (Asia/Shanghai)

## Headline

Counters REA #8154 (`trace callers of external DEX methods`) by planting a
byte-valid decoy `classesN.dex` whose caller classes each contain a real
`invoke-static` to `android.util.Log.d`. Saturates
`MAX_EXTERNAL_XREF_BYTES` (≈ 1 MiB) without touching the developer's root
manifest or rewriting their own DEX beyond the existing trailer shield.
